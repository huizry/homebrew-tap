# Huizry Tap

## How do I install these formulae?

`brew install huizry/tap/<formula>`

Or `brew tap huizry/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "huizry/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
